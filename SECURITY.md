# Security Policy

Sovereign Exchange is experimental software and is not production-ready trading infrastructure.

## Reporting a vulnerability

Do not publish credentials, private keys, exploitable payloads, or other sensitive details in a public issue.

For security-sensitive reports, use GitHub's private vulnerability reporting if enabled for this repository. Otherwise contact the repository owner privately through GitHub.

## Scope

Security reports are especially useful for:

- authentication or authorization bypasses
- journal tampering or recovery inconsistencies
- sequence/replay vulnerabilities
- failover/fencing failures
- memory-safety issues
- denial-of-service conditions
